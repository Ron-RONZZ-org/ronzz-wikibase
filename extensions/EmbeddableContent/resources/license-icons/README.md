# Creative Commons licence glyphs

The four official Creative Commons licence icons used on the PDF licence page
(`resources/license.js`):

| File | Icon |
|------|------|
| `cc.svg` | CC logo |
| `by.svg` | Attribution (BY) |
| `nc.svg` | NonCommercial (NC) |
| `sa.svg` | ShareAlike (SA) |

Source: the Creative Commons press kit,
<https://mirrors.creativecommons.org/presskit/icons/> (the same icons the
deed page at <https://creativecommons.org/licenses/by-nc-sa/4.0/> renders).

The icons are provided by Creative Commons for reuse with the licences. The
CC name and logo are trademarks of Creative Commons; the icon artwork is
distributed under the terms stated by Creative Commons for its downloads
(CC BY). They are used here only to identify the licence of the content, with
the licence deed linked next to them.
